# Hola Mundo

Programa sencillo en C++ que imprime `Hola Mundo` en la consola.

## Requisitos

- Un compilador de C++ compatible con C++17, como `g++`.

## Compilar

Desde la carpeta del proyecto, ejecuta:

```sh
g++ -std=c++17 -Wall -Wextra -pedantic Hola_Mundo.cpp -o Hola_Mundo
```

## Ejecutar

En Windows (PowerShell):

```powershell
.\Hola_Mundo.exe
```

En Linux o macOS:

```sh
./Hola_Mundo
```

Los ejecutables y archivos de compilación se excluyen del repositorio mediante `.gitignore`.
